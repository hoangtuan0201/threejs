# Welcome to AirSmart 3D Experience

> **The world's finest indoor environment system** - Experience AirSmart's cutting-edge HVAC technology through immersive 3D visualization.

## 🏠 What is AirSmart?

AirSmart is an intelligent air conditioning and air purification system designed to deliver perfect indoor air quality. We've created an interactive 3D experience so you can explore and understand how each component in the system works.

### 🌟 User Experience
- **Minimalist Design**: Beautiful, easy-to-use interface
- **Quiet Operation**: No noise, no drafts
- **Simple Maintenance**: Self-diagnostic system with maintenance alerts
- **Remote Control**: Mobile app allows control anytime, anywhere

## 🎮 How to Use the 3D Experience

### On Desktop Computer
1. **Navigate Timeline**: Scroll mouse wheel to move through the 0.1-18.1 second sequence
2. **Keyboard Controls**: 
   - Use left/right arrow keys to jump 0.3 seconds
   - Press ESC to return to homepage
3. **Hotspot Interaction**: 
   - Click on hotspots to activate camera controls
   - Drag mouse to rotate camera (limited to ±15°)
   - Scroll to zoom (1-20 units range)
4. **Chapter Navigation**: Use the navigation menu to jump to specific locations
5. **Path Tracing**: Enable GPU Path Tracing for 4K+ quality (powerful desktops only)

### On Mobile/Tablet
1. **Touch Navigation**: 
   - Swipe vertically to move through timeline
   - 30px threshold distinguishes vertical/horizontal swipes
2. **Gesture Controls**:
   - Tap hotspots to view details
   - Pinch-to-zoom when camera controls are active
   - Swipe to rotate camera in hotspot mode
3. **Mobile Optimization**:
   - Automatically adjusts quality (Low/Medium/High)
   - Reduces pixel ratio to 1.5 for optimal performance
4. **Home Button**: Floating Home button to return to main page
5. **Adaptive Performance**: Automatically reduces quality when battery is low or device overheats
