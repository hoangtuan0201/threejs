# AirSmart 3D Experience User Guide

## 🎮 Interactive 3D Navigation

### 🎬 Camera Movement Controls
**How to Navigate:**
- **Mouse Scroll**: Move through the timeline (0.1 to 18.1 seconds)
- **Arrow Keys**: Jump forward/backward by 0.3 seconds for precise positioning
- **ESC Key**: Return to homepage at any time
- **Smooth Transitions**: Camera automatically moves between viewpoints with easing
- **Scene Lock**: Navigation is temporarily disabled during automatic transitions

**Timeline Navigation:**
- The experience follows a 18-second sequence
- Each hotspot appears at specific timeline positions
- Use the chapter navigation menu for quick jumps
- Scroll sensitivity can be adjusted in settings

### 🎯 Hotspot Interaction Guide
**Finding Hotspots:**
- Look for glowing interactive points on the 3D model
- 14 hotspots are positioned throughout the system
- Each hotspot lights up automatically when in view
- Spotlights illuminate the area you're exploring

**Interacting with Hotspots:**
1. **Click/Tap** on any hotspot to activate it
2. **Camera Controls** become available (rotate ±15°, zoom 1-20 units)
3. **Video Screen** appears showing component demonstration
4. **Information Panel** displays technical details and benefits
5. **Close** by clicking the X or tapping outside the hotspot

**Mobile Hotspot Usage:**
- Tap hotspots to view details
- Pinch to zoom when camera controls are active
- Swipe to rotate camera around the component
- Separate positioning optimized for mobile screens

### 📱 Mobile Device Instructions
**Touch Controls:**
- **Vertical Swipe**: Navigate through timeline
- **Horizontal Swipe**: Ignored to prevent accidental navigation
- **Pinch Gesture**: Zoom in/out when viewing hotspots
- **Tap**: Select hotspots and interact with interface

**Performance Settings:**
- **Auto Quality**: System detects device capability (Low/Medium/High)
- **Battery Monitoring**: Quality reduces automatically when battery is low
- **Thermal Management**: Performance scales down if device overheats
- **Network Optimization**: Adapts to connection speed

**Mobile-Specific Features:**
- Floating Home button for easy navigation
- Optimized touch targets for finger interaction
- Reduced pixel ratio (1.5) for better performance
- Separate hotspot positioning for mobile screens

## 📊 Performance Optimization

### 🎮 GPU Path Tracing (Advanced)
**Enabling Path Tracing:**
1. Available on powerful desktop computers only
2. Look for "Path Tracing" toggle in advanced settings
3. Monitor rendering progress (768-3072 samples)
4. Wait for convergence for best quality

**Path Tracing Controls:**
- **Quality Presets**: Mobile (768 samples) vs Desktop (3072 samples)
- **Progress Monitoring**: Real-time rendering progress display
- **Auto-Reset**: Automatically restarts when camera moves
- **Performance Impact**: Significant GPU usage - use on powerful systems only

### 📱 Mobile Performance Tips
**Optimizing Mobile Experience:**
- **Close Background Apps**: Free up device memory
- **Use Wi-Fi**: Better performance than cellular data
- **Keep Device Cool**: Performance reduces when overheating
- **Charge Battery**: Low battery triggers performance reduction
- **Update Browser**: Use latest version for best compatibility

**Mobile Quality Tiers:**
- **Low**: Basic rendering, maximum compatibility
- **Medium**: Enhanced visuals, good performance balance
- **High**: Near-desktop quality for powerful mobile devices
